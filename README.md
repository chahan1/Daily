# 每日動力（daily）

Android 提醒 App（Kotlin）。依起床、睡覺時間自動排出一天的提醒，只收研究證據「中等以上」的建議，幫助每天維持精神和動力。

## 下載
APK：https://github.com/chahan1/daily/releases/download/latest/daily.apk

## 功能
- **一天的提醒**（依起床、睡覺時間自動排；每一項都可在設定裡開關）
  - 起床 +10 分：☀️ 出門曬太陽
  - 起床 +30 分：📝 寫今天的「如果…就…」
  - 💧 喝水（次數可設，平均分散在白天）
  - 睡前 8 小時：☕ 咖啡因到此為止
  - 自訂時間：🏃 運動（通知可直接打開運動 App `tw.chahan.walkcoach`）
  - 自訂時間：📚 學習（通知可直接打開英文筆記本，沒裝 App 就開網頁）
  - 睡前 60 分：⭐ 幫今天的精神打分
  - 睡前 30 分：📵 放下手機
  - 睡覺時間：🌙 上床睡覺
- 通知上有「✓ 完成」；App 裡點項目可看「為什麼」（研究根據與證據強度）
- **時間表**（0.2）：從起床到睡覺切成一格一格（每格 30 或 40 分鐘，設定裡選）
  - 內建提醒預設 🔒 固定，要先解鎖才能從時間表移除
  - 平時只顯示有項目的時段；按「編輯」才顯示空格和「＋」（0.3）
  - 編輯模式下，空格點「＋」加入自己的行程：名稱、備註、開始時間（提早／延後一格）、長度（加減一格）
  - 重複：每天／平日／只有今天／自選星期幾；可選開始時是否跳通知
  - 自訂行程也能 🔒 固定，固定後要先解鎖才能修改或刪除
- **早上紀錄**：昨晚睡了幾小時、今天精神 1～5 分
- **提不起勁？**：給一件 5 分鐘的小事，可直接開始 5 分鐘倒數（時間到會通知）
- **睡眠與精神**：最近 14 天長條圖；最近 30 天比較「睡滿 7 小時」和「不到 7 小時」的日子精神平均差多少
- **補正紀錄**（0.4）：點長條圖的某一天，或按「✏️ 補正前幾天的紀錄」從最近 30 天挑一天，可修改睡眠時數、精神分數、「如果…就…」和已完成項目；睡眠、精神都可清除成「未填」。按「儲存」才會寫入

## 沒有收進來的（證據弱或有爭議）
成長型思維、多巴胺排毒、起床延後 90 分鐘才喝咖啡、早餐與血糖、NSDR。

## 技術
- 用 AlarmManager 準時鬧鐘（`USE_EXACT_ALARM`），每次只排下一個，響了再排下一個；開機、改時間、更新 App 後自動重排。
- 鬧鐘延遲超過 2 小時（例如關機很久）就不補發。
- 資料存在 SharedPreferences（每天一筆 JSON：睡眠、精神、計畫、已完成項目）。
- 介面全部用程式畫（`Ui.kt`），不用 XML 版面。

## 編譯
推上 GitHub 後，Actions 自動編譯，APK 放在 Releases 的 `latest`。
簽署金鑰 `app/daily.jks` 固定不變，新版 APK 可直接覆蓋安裝。

## 手機設定（小米 HyperOS）
安裝後到 設定 → 應用程式 → 每日動力：
1. 省電策略 → 無限制
2. 自動啟動 → 開啟
3. 通知 → 允許
